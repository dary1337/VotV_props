# Как этим пользоваться ?
-   Скачайте [Universal Unreal Engine Unlocker](https://framedsc.com/GeneralGuides/universal_ue4_consoleunlocker.htm) — если доверяете рандому из интернета
-   Распакуйте UUU Unlocker
-   Запустите VotV
-   Дождитесь главного меню
-   Запустите UUU Unlocker
-   Inject DLL
-   Появится сообщение: `Console is activated. Press ~ to open the console`
-   Загрузите сейв
-   Откройте консоль и используйте команду `summon`. Например: `summon prop_physgun_c`

## Списки пропов

сами ID пропов в английской версии — они не переводятся. полный каталог здесь → [README.md](https://github.com/dary1337/VotV_props?tab=readme-ov-file#new-props-from-my-latest-update-090d--090m).

ниже короткая выжимка по интересным.

### Структура каталога

- **0.9.0d → 0.9.0m:** мебель, новые `prop_woodentable_*`, `prop_iron*`, шапка-наушники, `prop_kerfurOmega_asmodena_c`.
- **0.8.2c → 0.9.0d:** огромное обновление — апгрейды квадроцикла (`prop_atvUpgrade_*`), фановые пушки в стиле Madness Combat (`prop_funGun_*_mc_c`), флоппи-диски всех цветов, физ-модули, инструменты, стулья, спальники.
- **0.8.2 → 0.8.2b:** воздушные шарики, ультра-камера, экипировка служанки (`prop_equipment_maid_c`).
- **0.8 → 0.8.2:** старт большой части механик — оборудование (компас, EMF, гейгер, металлодетектор), готовка, xmas-контент, плюшки `dingus`/`erie`, физган и гравган.

## Интересные пропы (краткий гид)

- **Плюшки argemia / erie / kerfur / monika** — `prop_arg*_c`, `prop_erieHold_*`, `prop_kerfurOmega_*`, `prop_monikaPlush_c`.
- **Аррирал-предметы (`prop_arir*_c`)** — оружие и контейнеры пришельцев.
- **Фановые пушки:**
  - `prop_funGun_propgun_c` — копирует пропы и стреляет ими. любимая.
  - `prop_erieGun_c` — стреляет эриями, которые пожирают всё.
  - `prop_arirDisint_c` — дезинтегратор аррирал, ПКМ — удалить.
  - `prop_comet_c` / `prop_rifleComet_c` — кометы, взрываются от касания.
- **Инструменты:**
  - `prop_physgun_c` — физган. выбор гигачадов.
  - `prop_gravgun_c` — гравган, что тут ещё сказать.
  - `prop_lasertest_lightsaber_c` — самый безопасный лазер.
  - `prop_modelmanipulator_c` — ПКМ скопировать модель, ЛКМ применить.
- **Madness Combat:** `prop_grunt_c`.
- **Xmas:** `prop_xmasgift_c`, `prop_xmaslights_c`, `prop_xmastree_c`, венки.

Полные описания → [English README](https://github.com/dary1337/VotV_props?tab=readme-ov-file#interesting-props).
