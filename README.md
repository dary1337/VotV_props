# How to use it ?
-   Download [Universal Unreal Engine Unlocker](https://framedsc.com/GeneralGuides/universal_ue4_consoleunlocker.htm) from this link if u trust a random guy from the internet
-   Unpack the UUU Unlocker.
-   Launch VotV
-   Wait for the menu buttons
-   Launch the UUU Unlocker
-   Inject the DLL.
-   Once it's done, you’ll see a message: `Console is activated. Press ~ to open the console`
-   Load the save
-   Open the console and use command `summon`. For example: `summon prop_physgun_c`

## It is working in storymode ?

## I didnt see a message about the console
