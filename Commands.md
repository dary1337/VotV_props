# Voices of the void UUU commands

`Teleport` - teleports you where u looking at  

`ToggleDebugCamera` also (EnableDebugCamera & DisableDebugCamera)  

`ShowDebug` - works as a toggle, shows player location  

`Open` for example `open untitled_196` - opens the project file  

`Summon` for example `summon prop_physgun_c` - summons a prop
